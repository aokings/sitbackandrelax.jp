Kebijakan Privasi

Yarikuri Lokal (yrkr.local)

Yarikuri Lokal ("Aplikasi") adalah aplikasi untuk mengelola uang saku anak. Kebijakan ini menjelaskan bagaimana kami menangani privasi Anda.

1. Informasi yang Kami Kumpulkan

Aplikasi ini tidak mengumpulkan informasi pribadi apa pun.

  • Tidak perlu registrasi akun
  • Semua data seperti nama dan jumlah disimpan secara lokal di perangkat Anda
  • Tidak ada data yang dikirim ke server mana pun

2. Cadangan iCloud

Aplikasi ini menyediakan cadangan otomatis menggunakan iCloud Documents.

  • Data cadangan disimpan di penyimpanan iCloud Anda, terkait dengan Apple ID Anda
  • Pengembang tidak dapat mengakses data ini
  • Cadangan dapat dinonaktifkan kapan saja dari pengaturan aplikasi

3. Penggunaan Kamera

Aplikasi ini menggunakan kamera untuk memindai kode QR.

  • Gambar yang diambil kamera hanya digunakan untuk analisis kode QR dan tidak disimpan atau dikirim

4. Berbagi Data melalui Kode QR

Aplikasi ini menggunakan kode QR untuk berbagi data antara perangkat orang tua dan anak.

  • Kode QR berisi riwayat transaksi (jumlah, alasan, tanggal)
  • Kode QR ditampilkan dan dipindai langsung antar perangkat, tanpa menggunakan internet

5. Layanan Pihak Ketiga

Aplikasi ini tidak menggunakan layanan analitik, iklan, atau pelacakan pihak ketiga apa pun.

6. Privasi Anak

Aplikasi ini dirancang untuk digunakan oleh anak-anak. Kami tidak mengumpulkan, menyimpan, atau mengirim informasi pribadi dari anak-anak. Semua data tetap di perangkat.

7. Perubahan

Kebijakan ini dapat diperbarui sesuai kebutuhan. Jika ada perubahan signifikan, kami akan memberi tahu Anda melalui aplikasi.
